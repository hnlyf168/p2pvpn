推荐：平台生成专属安装命令

登录 → 创建网络（支持自定义网段）→ 添加设备 → 复制命令执行。安装脚本自动下载、校验 SHA-256、领取设备配置并安装开机自启服务；不需要单独生成或输入加入密钥。

每条命令仅对应一台设备，30 分钟内有效。同一设备安装失败可在有效期内重试，不会重复创建设备；换另一台设备请重新生成命令。不要公开分享安装命令。

安装界面会显示“等待执行”“已加入网络”“设备已上线”。至少添加两台同组设备，才可以通过虚拟地址互相访问。

已有其他设备配置时，专属安装脚本会停止，避免覆盖旧网络。如需升级已安装客户端，可使用下载中心的通用脚本保留原配置；如需更换网络，请先备份并卸载旧客户端。

手动安装 Windows 客户端

解压安装包，把 client.json 放在 P2PVpnClient.exe 旁，双击“安装客户端.cmd”并允许管理员权限。保留同目录的 wintun.dll。

P2PVpnClient.exe check
P2PVpnClient.exe run

Linux 客户端

系统需要 /dev/net/tun 和 ip 命令。解压后将配置放在可执行文件旁：

sudo sh install-linux.sh
systemctl status edge-vpn

部署独立中继或备用打洞节点

  1. 管理员在运营后台创建对应类型的节点，配置公网地址。
  2. 下载一次性节点配置 node.env，不要公开其中的 NodeKey。
  3. 在另一台 Linux 主机解压对应节点包，将 node.env 放入同一目录。
  4. 执行 sudo sh install-node.sh，节点开始向主站发送心跳。
  5. 中继节点还需配置 WSS 反向代理与 TLS；打洞节点需开放与主站相同的 TCP/UDP 协调端口段。

安装包内提供 systemd 服务、配置示例与反向代理说明。普通用户不能注册平台节点。

校验与排查

  • 每台设备使用不同的 client.json，共用配置会造成设备互相顶替。
  • 同一分组才能互相发现。普通会员打洞失败后不会经过主服务器中转。
  • 已吊销的设备需要重新加入；加入密钥吊销不等于移除已加入设备。
  • 备用打洞按主备方式使用，当前不支持不同协调节点之间的实时发现。
  • 原项目的旧客户端和 Android APK 不支持本版设备认证，请使用本下载中心提供的版本。
