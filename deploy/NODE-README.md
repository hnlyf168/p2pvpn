# Edge VPN 独立节点 v0.3.0

适用于 Ubuntu 22.04/24.04 x64、Debian 12 x64 等具有 glibc、OpenSSL 3、libicu 的 Linux。已包含 .NET 运行时。需要独立公网主机及 systemd。

1. 平台管理员登录官网 /ops → 基础设施节点 → 注册独立节点。
2. 打洞节点入口填写域名/IP（不带端口）；中继入口填写 wss://relay.example.com/relay。
3. 下载一次性 node.env，放在 install-node.sh 旁。凭据不得公开，不要放入网站目录。
4. 执行 `sudo sh install-node.sh`。安装器创建专用低权限服务账号，配置保存在 /etc/edge-vpn-punch 或 /etc/edge-vpn-relay，权限 600。
5. `sudo journalctl -u edge-vpn-relay -n 50`（打洞节点改为 edge-vpn-punch）。在运营后台确认在线。

## 中继节点

node.env 默认只监听 127.0.0.1:5081。安装 Caddy 后，将以下配置中的域名替换为已经解析到本机的域名：

```
relay.example.com {
    reverse_proxy 127.0.0.1:5081
}
```

开放 TCP 80/443，使用有效 TLS 证书，保证 WebSocket 可升级。不要把 5081 直接暴露公网。中继只接受通过设备凭据认证且当前享有高级会员权益的设备；授权定期复核，按设备限速。中继转发的是客户端组密钥加密的负载。

## 备用打洞节点

开放与控制平面相同的 TCP/UDP 协调端口段，默认 49000–49099。节点自动同步网络端口和认证快照。健康检查 HTTP 5081 无需公开。不得与同一主机的主协调服务抢占端口。

当前为主备协调架构，节点之间不联邦发现；所有设备应采用相同主备顺序，故障切换可能短暂中断。过期认证快照拒绝新连接。

## 升级、撤销和卸载

升级时保留 node.env，在新安装包目录重新执行安装器，旧程序保留在 releases 目录可回滚。撤销节点请先在运营后台操作，然后 `sudo systemctl disable --now edge-vpn-relay`。平台每 15 秒接收心跳，60 秒无心跳不再分配；现有连接按重新鉴权周期失效。配置泄露时撤销节点并重新注册。

高级会员只获得可用中继权限；没有部署并上线节点时，没有中继兜底。主服务器始终不转发用户数据。

## v0.3.0 功能

控制台的“一键添加设备”默认生成一次、24 小时有效的加入码，Windows 下载 /install.cmd 后双击，Linux 从下载中心复制安装命令。脚本从 HTTPS 下载对应客户端并校验 SHA-256，交互输入加入码，自动领取配置和安装服务。重复安装保留同平台的已有设备身份与配置。

用户创建网络时可填写 RFC1918 私有 IPv4 CIDR，支持 /8–/30；同账号网络不得重叠，已有有效设备时不能直接改网段。地址分配、主备协调握手和中继目录均携带正确前缀。使用自定义网段前请将客户端和所有独立节点更新到 v0.3.0。

管理员可查看所有用户的邮箱验证、会员、网络、分组、设备与审计信息，以及全平台真实在线连接；密码、加入码原文和 SMTP 授权码不在查询接口中显示。历史账号保留登录能力并标记为未验证，不会自动伪装成已验证。在线依据主协调连接和节点上报，配置同步不计为在线。
